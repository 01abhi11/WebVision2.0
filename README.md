# BloodLink 🩸 - Emergency Blood Network

## 🚨 The Problem Statement
India collects millions of units of blood annually, and government platforms like e-RaktKosh have over 28 lakh registered donors. However, in a medical emergency, these databases fail the end-user:
1. **High Cognitive Load:** Distressed families do not have the time or state of mind to navigate complex, multi-page web forms during the golden hour.
2. **The Incentive Flaw:** Peer-to-peer donor networks suffer from low retention because they rely purely on unorganized altruism.

## 💡 Our Solution
**BloodLink** is an ultra-fast, zero-friction emergency blood matching web app designed for high-stress medical emergencies.

Instead of typing through cluttered forms, users tap a single microphone button and speak naturally in Hindi or English (e.g., *"Mujhe O-Negative blood chahiye AIIMS Delhi ke paas"*). The system extracts the required blood group, hospital location, and urgency to match nearby verified donors instantly.

## 🔥 Key Differentiator: The Lifesaver Perks Ecosystem
Since paying for blood is illegal in India, **BloodLink** solves donor retention through a **Lifesaver Tier** system. Active donors earn verified badges after each scheduled donation, unlocking partner rewards (e.g., 20% off at pharmacies, priority diagnostic checkups, and cafe vouchers).

## 🛠 Tech Stack
* **Frontend:** HTML5, Tailwind CSS
* **Voice & Logic:** Vanilla JavaScript (Speech Recognition & Entity Extraction flow)
* **Hosting:** GitHub & Vercel
